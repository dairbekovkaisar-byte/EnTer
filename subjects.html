Какую пару выбрать.

Пара зависит от специальности, на которую ты поступаешь. На ЕНТ можно сдавать такие сочетания.

Математика + Физика
Математика + Информатика
Математика + География
Биология + Химия
Биология + География
Химия + Физика
География + Иностранный язык
Иностранный язык + Всемирная история
Всемирная история + География
Всемирная история + Основы права
Казахский язык + Казахская литература
Русский язык + Русская литература

Для творческих специальностей есть творческий экзамен, к нему мы не готовим. Какая пара нужна для твоей специальности, проверь на сайте Национального центра тестирования.
