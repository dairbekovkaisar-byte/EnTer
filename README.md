# ENTer: сайт и приложение для подготовки к ЕНТ

Сайт: https://dairbekovkaisar-byte.github.io/enter/

Приложение: https://dairbekovkaisar-byte.github.io/enter/app.html

Папка `dist` это готовый сайт. Его можно выложить на любой статический хостинг: файлы копируются как есть, сервер и база данных пока не нужны.

## Что внутри

- `dist/` готовый сайт: 26 страниц на русском и казахском и приложение (`app.html`, `kk/app.html`).
- `src/` исходники: тексты страниц (`ru.js`, `ru2.js`, `kk.js`, `kk2.js`), шаблоны, стили. В `src/app/` приложение и задания.
- `build/` сборка и проверки.

## Как обновить сайт на GitHub Pages

Сайт отдаёт GitHub Pages из ветки `gh-pages`: в ней лежит только содержимое `dist`. Исходники лежат в `main`.

Поменял тексты или задания? Запусти из папки проекта:

```
sh build/deploy.sh "Что изменилось"
```

Скрипт пересоберёт сайт под адрес GitHub Pages, сохранит изменения в `main` и выложит `dist` в `gh-pages`. Сайт обновится через минуту-две.

## Как выложить на свой домен

1. Поставь Node.js и Python 3.
2. Укажи домен и пересобери, чтобы ссылки для поисковиков и соцсетей вели на него:
   `SITE_URL=https://твой-домен.kz node build/site.mjs && node build/app.mjs`
3. Загрузи содержимое `dist` в корень сайта. Настрой страницу 404 на `404.html`, если хостинг этого не делает сам.

Если домен подключаешь к GitHub Pages (Settings → Pages → Custom domain), запускай `deploy.sh` с ним: `SITE_URL=https://твой-домен.kz sh build/deploy.sh`.

Папку `dist/assets` не удаляй: иконки и картинки лежат только там.

## Что заменить перед запуском

В `src/ru.js`, `src/ru2.js`, `src/kk.js`, `src/kk2.js` и `src/app/strings.js` остались метки, которые заполняешь ты:
`[ЦЕНА]`, `[БАҒА]`, `[НОМЕР]`, `[АДРЕС]`, `[ВРЕМЯ]`, `[УСЛОВИЯ ВОЗВРАТА]`, `[ЮРЛИЦО, БИН, АДРЕС, РАСЧЁТНЫЙ СЧЁТ]`, `[ТЕКСТ ОТ ЮРИСТА]`, `[СРОК]`, `[СПИСОК: СМС, ОПЛАТА, ХОСТИНГ]`, `[ЮРЛИЦО]` и такие же метки на казахском.

## Что пока работает только в браузере

Прогресс хранится в браузере ученика (`localStorage`), на другом устройстве его не будет.
Не подключены и показаны в приложении как демо:

- вход по СМС: подходят любые 4 цифры;
- оплата Kaspi и картой: кнопка открывает полный доступ без списания;
- отчёты родителям в WhatsApp и напоминания: настройки сохраняются, сообщения не уходят;
- сообщение об ошибке в задании: показывает номер задания и контакты.

## Задания

Всего 1525 заданий: 125 написаны вручную (история, чтение), 1400 сделаны из 133 шаблонов (математическая грамотность, математика, физика), где цифры меняются, а ответ считает код. Настоящих вариантов НЦТ здесь нет, ни одно задание пока не проверено учителем.

- `src/app/q-hist-read.js`, `src/app/q-hist2.js`: задания по истории и чтению.
- `src/app/q-gen.js`, `src/app/q-gen2.js`: шаблоны.
- `bank-review.csv`: таблица для учителя, 258 строк: все ручные задания и по одному примеру каждого шаблона. Открывается в Excel, в конце есть колонки для статуса и комментария. Пересоздать: `node build/export-bank.js`.

Полностью готова пара «Математика + Физика». В других парах пока работают только обязательные предметы и математика или физика, если они есть в паре.

Новые шаблоны и задания добавляй только в конец списков: от порядка зависят номера заданий, а к ним привязан прогресс учеников.

Казахские тексты должен проверить носитель языка.

## Проверки

Запусти сервер из `dist` на порту 8766 (`python3 -m http.server 8766 --bind 127.0.0.1`), нужен Playwright:

- `node build/check-bank.js` проверяет каждое задание;
- `node build/links.js` проверяет все ссылки;
- `node build/e2e.js` и `node build/e2e2.js` проходят приложение целиком;
- `node build/phone.js` проверяет экраны на ширине от 320 до 1920;
- `node build/mid.js` снимает экраны на средних ширинах, где колонки могут сжиматься;
- `node build/site-check.js` проверяет страницы сайта;
- `node build/shots2.js` переснимает экраны приложения для страниц сайта.
